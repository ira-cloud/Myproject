# Cycle & Nutrient Syncing App — Stage 1 (Free MVP) Design

## 1. Product Vision

Персональный ассистент по женскому здоровью и питанию, синхронизированный с фазами
менструального цикла. Ежедневно приложение смотрит на текущую фазу цикла и
самочувствие пользовательницы (отмеченные симптомы) и подсказывает, что съесть
сегодня и почему — простыми словами, без подсчёта калорий и взвешивания еды
(порции "на глаз": ладонь, кулак, ложка).

Ключевые принципы (зафиксированы на основе полного разбора идеи, см.
`Анализ идей приложений для женского здоровья.pdf`):

- **Food-First, не медицина.** Приложение — категория "Lifestyle & Wellness", не
  Medical Device. Никаких диагнозов, никаких назначений лекарств/БАД с дозировками.
  Формулировки только в духе "продукты, богатые X" / "состояния, часто связанные с
  фазой Y" / "стоит обсудить с врачом".
- **Приватность по умолчанию (Local-First).** Все личные данные (даты цикла,
  симптомы, настройки) хранятся только на устройстве пользователя. Нет сервера,
  нет аккаунта, нет сбора PII. В v1 нет обращений к интернету вообще.
- **Zero Judgment.** Не запрещаем кофе/алкоголь/сладкое — снижаем вред и объясняем
  физиологию без чувства вины. Не используем слова "диета", "вредная еда",
  "запрещено" (профилактика РПП).
- **Растёт поэтапно.** Это Stage 1 (Free) — ядро продукта. Pro-версия (анализы
  крови, Oura Ring, кастомные напоминания, ИИ-генерация) — отдельный этап,
  вне рамок этого документа.
- **Свобода выбора, не диктат.** Там, где для одной физиологической потребности
  подходит несколько продуктов, приложение показывает их как равнозначные
  варианты на выбор, а не навязывает один "правильный" рецепт (см. §4.5).
- **Локализация контента, не только интерфейса.** Большинство конкурентов (Flo,
  Clue, 28) переводят интерфейс, но продукты в рекомендациях остаются
  западными (авокадо, киноа, лосось) — дорогими и непривычными для украинской/
  русскоязычной аудитории. Наша база знаний с самого начала включает
  доступные локальные продукты (гречка, кефир, творог, печень, квашеная
  капуста, семечки) наравне с международными альтернативами — без иерархии
  "лучше/хуже", просто выбор (см. §4.5).

## 2. Scope Decisions (подтверждено с пользователем)

| Вопрос | Решение |
|---|---|
| Платформа | React Native + Expo. iOS — первым, Android добавляется тем же кодом позже. |
| Объём первой сборки | Узкое ядро (цикл, фазы, симптомы, тарелка дня). Остальные модули из PDF (SOS-кнопки, утренний ритуал, спорт, привычки, кастомные напоминания) — fast-follow после того, как ядро протестировано. |
| ИИ в v1 | Нет. Только локальный движок правил (JSON база знаний внутри приложения). ИИ-шлюз — будущая версия. |
| Нерегулярный цикл | Да, базовая гибкость заложена в v1 (см. §4.2). |

## 3. Architecture

- **Стек:** Expo (React Native + TypeScript), expo-router (навигация), NativeWind
  (стили), expo-notifications (локальные пуши).
- **Хранение данных:** SQLite на устройстве (expo-sqlite). Никакого бэкенда.
- **Резервное копирование:** данные приложения не исключаются из стандартного
  iCloud-бэкапа устройства — при смене телефона восстанавливаются автоматически.
  Отдельная функция экспорта — не в v1.
- **Сеть:** приложение работает 100% офлайн. Никаких API-вызовов, аккаунтов,
  аналитики с передачей персональных данных.

## 4. Функциональные блоки (разделение по задачам)

### T1. Data Layer
Локальная SQLite-схема:
- `UserProfile` — дата последних месячных, средняя длина цикла, длина менструации,
  диетические ограничения, уровень интенсивности (Light/Medium/Super).
- `CycleEntry` — история дат начала месячных (по мере использования пополняется).
- `SymptomLog` — дата + список тегов симптомов (тело/настроение/аппетит).
- `Settings` — заготовка под будущие переключаемые модули (в v1 активен только
  модуль "Food & Cycle").

### T2. Phase Engine (ядро расчёта)
Определяет текущий день цикла и одну из 4 фаз (менструальная 1–5, фолликулярная
6–12, овуляторная 13–15, лютеиновая 16–28 — границы адаптируются под длину цикла
пользователя).

**Логика адаптивности:**
- Меньше 2 циклов в истории → используем среднюю длину цикла, введённую при
  онбординге.
- 3+ цикла в истории → пересчитываем скользящее среднее по фактическим датам,
  а не только по введённому вручную числу.
- Если разброс между последними циклами больше 7 дней → включается "мягкий режим":
  вместо категоричного "День 21, лютеиновая фаза" показываем "Ориентировочно
  лютеиновая фаза" и не даём жёстких прогнозов даты следующей фазы. Это базовая
  защита для пользовательниц с нерегулярным циклом (ПКЯ, послеродовой период,
  перименопауза), не пытаясь при этом ставить диагноз.

### T3. Onboarding
Короткий сценарий (5 экранов вместо изначальных 10 из черновика):
1. Disclaimer — согласие с условиями и юридическим дисклеймером (обязательный
   шаг, без него нет входа в приложение).
2. Параметры цикла — дата последних месячных, средняя длина цикла, длина
   менструации.
3. Диетические ограничения — всеядное / вегетарианство / без лактозы / без
   глютена / другое.
4. Интенсивность подхода — Light (сохранить привычки, минимизировать вред) /
   Medium (мягкие замены) / Super (максимальная перестройка).
5. Готово → переход на главный экран.

На экране 2 (параметры цикла) для длины цикла и менструации доступен вариант
"Не уверена точно" с разумным дефолтом (28 дней / 5 дней), чтобы не терять
пользовательницу, которая не помнит цифры наизусть — точность донастроится
сама по мере использования (см. T2).

*Отложено на fast-follow:* выбор цели (ПМС / подготовка к беременности /
восстановление) — в v1 работает единый сценарий "Баланс и синхронизация",
углублённые сценарии добавятся позже, когда появится контент под них.

### T4. Daily Dashboard (главный экран)
- Карточка фазы: день цикла, название фазы, понятная визуализация естественного
  баланса эстроген/прогестерон.
- Быстрый чек-ин симптомов (10–30 секунд): теги по трём группам — тело
  (отёки, вздутие, спазмы, акне), настроение (апатия, раздражительность,
  тревожность), аппетит (тяга к сладкому/солёному).
- «Тарелка дня»: конструктор приёма пищи по категориям (белок, сложные углеводы,
  полезные жиры, чай/специя дня — см. §4.5) под текущую фазу и отмеченные
  симптомы, порции в понятных единицах — ладонь (белок), кулак/сложенная ладонь
  (углеводы/овощи), столовая/чайная ложка (жиры).
- Объяснение «почему сегодня так» — короткий физиологический текст, собранный из
  шаблонов базы знаний (T5), не сгенерированный ИИ.

### 4.5 Равнозначные варианты (Food & Herb Equivalency)

Внутри каждой категории тарелки дня (белок / углеводы / жиры / чай-специя)
пользовательнице показывается не один рецепт, а несколько **равнозначных**
вариантов с одинаковым физиологическим эффектом — она выбирает то, что у неё
есть или что ей ближе. Варианты помечаются иконкой выбора ⇄ (не "лучше/хуже",
а просто альтернатива).

Пример (сложные углеводы, лютеиновая фаза):
`🌾 Гречка ⇄ 🍚 Киноа ⇄ 🥔 Батат` — все три дают медленную глюкозу и поддержку
синтеза прогестерона.

Набор вариантов всегда включает доступные локальные продукты (гречка, кефир,
творог, печень, свёкла, семечки подсолнечника, квашеная капуста) наравне с
более "международными" альтернативами (киноа, авокадо, лосось) — без
иерархии, просто ширина выбора.

**Чаи и специи** — отдельная категория в конструкторе тарелки, с той же логикой
равнозначных вариантов под фазу цикла: например, в менструальной фазе —
имбирный чай ⇄ чай с куркумой (противовоспалительное); в лютеиновой —
ромашковый чай ⇄ чай с корицей (спазмолитик / чувствительность к инсулину); в
фолликулярной — зелёный чай ⇄ мята.

### T5. Content / Rules Engine
JSON база знаний внутри приложения (без сервера), структура:
`фаза → фокус-нутриенты → группа равнозначных продуктов-источников →
визуальная порция → текст объяснения`. Каждая категория (белок, углеводы,
жиры, чай/специя) хранит **список** вариантов с одинаковым эффектом, а не один
продукт (см. §4.5) — обязательно с балансом локальных доступных продуктов и
международных альтернатив. Дополнительно — таблица `симптом → корректировка
рекомендации` (например, тяга к сладкому в лютеиновой фазе → акцент на магний
и сложные углеводы) и отдельный блок трав/специй по фазам.

Источники контента — открытые нутрициологические данные (USDA, рекомендации ВОЗ/
EFSA), формулировки строго в рамках юридических гардрейлов §6.

### T6. Local Notifications
Только два типа в v1, оба локальные (без сервера):
1. Смена фазы — уведомление за 2 дня до перехода в новую фазу.
2. Вечерний чек-ин — напоминание отметить симптомы дня.

*Отложено на fast-follow:* кастомные напоминания пользователя (приём витаминов и
т.д.), напоминания по привычкам, утреннему ритуалу.

### T7. Legal & Disclaimer Gate
- Обязательный экран согласия при первом входе (текст: приложение носит
  информационный характер, не является медицинской консультацией/диагностикой/
  назначением лечения).
- Мелкая дисклеймер-плашка под любой карточкой с нутриентной рекомендацией.

### T8. Личные закономерности (Local Pattern Recognition)
После накопления 2–3 циклов симптомов приложение локально (без ИИ, простой
статистикой по датам из T1) подмечает повторяющиеся закономерности и показывает
их как заботливое наблюдение, не диагноз — например: «Похоже, вздутие у тебя
чаще случается на 20–22 день цикла». Использует те же данные, что уже
собираются в T1/T4, без дополнительной инфраструктуры.

## 5. Explicitly Out of Scope for v1 (fast-follow within Stage 1)

- Выбор цели (Fertility Prep / Восстановление после КОК) и их отдельный контент.
- Модуль «Утренний ритуал» (вода/лимон/коллаген, тайминг завтрака).
- Модуль «Движение и спорт» по фазам цикла.
- Модуль «Привычки» (кофе/алкоголь/сигареты, лайфхаки снижения вреда).
- 5 SOS-кнопок (спазмы, вздутие, сахарный срыв, кофе/стресс, алкоголь).
- Кастомные напоминания пользователя.
- ИИ-генерация рецептов и ИИ-шлюз.
- Интеграция с Apple Health / Oura Ring.
- Модульные переключатели интерфейса (виджеты вкл/выкл) — архитектурно
  подготовлено в T1 (`Settings`), но UI переключателей не строим, пока нет
  вторых модулей.

## 6. Legal / Safety Guardrails (обязательны для контента и кода)

- Запрещены слова "диагноз", "лечение", "у вас дефицит X".
- Запрещены конкретные лечебные дозировки БАД и названия фармпрепаратов/брендов.
- Разрешено: формы нутриентов ("магния глицинат"), продукты-источники, отсылки к
  нормам ВОЗ/EFSA, формулировки "стоит обсудить с врачом".
- Запрещены категоричные пищевые запреты ("вредная еда") — профилактика РПП.
- Никакая персональная информация не покидает устройство ни при каких условиях
  в v1 (нет сети, нет аналитики со сбором PII).
